# FDS Case Study: Logistic Regression

## Objective
To build a Logistic Regression model that predicts passenger survival using the Titanic dataset.

## Dataset
The Titanic dataset contains passenger information, including age, gender, passenger class, and survival status.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Methodology
1. Data Exploration and Visualization
2. Data Preprocessing
3. Logistic Regression Model Building
4. Model Evaluation
5. Interpretation of Model Coefficients

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- ROC Curve

## How to Run
1. Open `FDS_Logistic_Regression.ipynb` in Google Colab.
2. Upload `titanic.csv` to the Colab session.
3. Run the notebook cells sequentially.
